# Apple Full Stack Project
## Full-stack Apple-themed e-commerce application
### Features: React frontend + Node.js/Express backend + MySQL

## Run locally

1. Copy `apple-fullStack/server/.env.example` to `apple-fullStack/server/.env` and set your MySQL credentials.
2. In `apple-fullStack/server`, run `npm run dev`.
3. In `apple-fullStack/client`, run `npm run dev`.

The frontend runs at `http://localhost:3000` and the backend runs at `http://localhost:3001`.
